Key Features

Everything you need, nothing you don't.

Engineered from scratch for competitive gamers, streamers, and low-latency communication.

🎙️

True Opus PLC & Studio Audio

Synthesizes missing packets seamlessly via Opus Packet Loss Concealment, eliminating crackling and dropouts in music bots and unstable voice calls.

👑

Custom Speech Priority Ducking

Assign priorities to voice participants. When squad leaders or shot-callers speak, lower-priority voices duck smoothly in real time.

⚡

DeepSleep Tray Optimization

Minimizing to system tray drops CPU consumption to 0.0%, suspending UI rendering while voice communication runs smoothly in background.

🛡️

Windows DPAPI Token Encryption

Local authentication tokens are encrypted with Windows master keys at rest (`CryptProtectData`), shielding your credentials from info-stealers.

🎛️

Auto-Persistent Audio Profiles

Mic sensitivity (VAD threshold), volume sliders, priority values, and input/output audio hardware are remembered across restarts.

🚀

Single 8 MB Standalone Binary

Zero dependencies, zero Chromium instances, zero Node.js runtimes. Native compiled machine code built for longevity.
